# Дизайн Exel

Нативний інтерфейс .NET MAUI для Windows / .NET 10. Власна темна палітра: тло #10131A, поверхні #191E28, заголовки #222936, текст #E7EDF7, другорядний текст #929EB1, бурштиновий акцент #E8BB75, сині команди #375C9B. Вибрана клітинка #263956; помилки #402B33 з текстом #FFB3A9.

Exel стоїть в крайньому лівому куті головної панелі, під ним менша назва документа. Системний заголовок вікна передається через Unicode API Windows, щоб українська назва документа коректно відображалася також на панелі завдань і в Alt+Tab. Зверху: меню; згруповані файлові команди, історія, режим і обчислення; адреса й рядок формули; компактні команди таблиці та скасування. Унизу лише пояснення результату й стан. Ліва панель документів ховається кнопкою, звільняючи місце для сітки.

Початковий документ 100 × 26, порожній. Сітка малює лише видиму ділянку на одній GraphicsView; одна нативна Entry перевикористовується для всіх клітинок. Немає тисяч контролів. Рядки заввишки 34, стовпці завширшки 144; заголовки рядків і стовпців залишаються видимими, активні заголовки виділено. Прокручування колесом, Shift+колесом, крайовими смугами; перехід через поле адреси.

Один клік вибирає. Подвійний клік/F2/Ctrl+A відкриває редактор, Ctrl+A виділяє весь текст. Native KeyboardAccelerator вікна передає команду редактору клітинки. Після завершення розкладки передбачено повторне встановлення фокусу; успішне виділення не повторюється без потреби. Enter/Tab застосовує й переходить далі, Escape скасовує чернетку. Стрілки рухають вибір поза редактором. У верхньому полі формули Ctrl+A діє як звичайна текстова команда.

Для вставлення посилання є явна кнопка: наступний клік вставляє адресу в позицію курсора, залишаючи вихідну клітинку активною. Це прибирає неоднозначність звичайного кліку. Редактор підтримує необов’язковий початковий =. Діапазонів чи перетягування заповнення немає.

Обчислення відбувається в робочому потоці на копії таблиці. BigInteger-текст готується там само й кешується. Вибір клітинки та перемикання режиму повторно використовують незмінні результати; після редагування перераховується вся таблиця. «Синтаксис» окремо запускає лише розбір. Доступне скасування. Це не інкрементальний граф залежностей.

Історія містить до 40 станів: дані, розміри, назва й адреса вибору. Ревізія збереження визначає, чи є зміни після Undo/Redo. Копії словника використовують ті самі незмінні рядки формул. Після завантаження іншого документа історія починається заново.

Кнопки зменшуються до 96% й змінюють прозорість під час натискання; команди не чекають анімації. Рамка вибору коротко пульсує. Довгі результати обмежено й обрізано в межах клітинки; повний текст доступний окремо.

Файли відкриваються/зберігаються через системні діалоги. Локальна бібліотека запам’ятовує шляхи, а не копії даних. Google Drive винесено в незалежний проєкт Exel.Integration з підставним HTTP-транспортом і часом для тестів; локальний callback використовує TcpListener. Дизайн використовує знайомі принципи електронних таблиць. Повне озвучення намальованої сітки, форматування діапазонів і XLSX не реалізовано. UML немає.
