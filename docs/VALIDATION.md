# Перевірка Exel

Дата: 2026-11-10. Windows x64; застосунок .NET 10 / MAUI 10.0.110, ядро та інтеграція — net10.0. Поточний синтаксичний аналізатор — ANTLR 4.13.1.

## Автоматизовані перевірки

**167 тестових випадків пройшли, 0 помилок, 0 пропущених.** Це загальна кількість запусків Fact і параметризованих Theory, а не 167 окремих методів. Тести використовують Microsoft.NET.Test.Sdk 18.7.0, xUnit 2.9.3 та xunit.runner.visualstudio 4.0.1.

```powershell
dotnet test tests/Exel.Tests/Exel.Tests.csproj -c Release
```

| Група | Що перевірено |

| AntlrFormulaTests | компактні посилання до CV100, точні позиції помилок, повне споживання вводу, відхилення відновленого помилкового дерева, Unicode-пропуски, права асоціативність степеня, межі рекурсії та довгі плоскі вирази |
| DependencyTests | порожні клітинки, спільні залежності, прямі та непрямі цикли, поширення помилок, розрив циклу, копія стану, обмеження ланцюжків і скасування |
| DocumentTests | адреси, розріджене зберігання, JSON round-trip, межі 100 × 100, відхилення 101 рядка/стовпця, нормалізація порожніх клітинок, розмір JSON у UTF-8 байтах |

| DriveTests | OAuth-конфігурація, PKCE/state, callback, scope, пагінація, створення/оновлення/читання файлу, поновлення токена, збереження та відновлення сеансу, вихід, ротація refresh token, відкликаний доступ і тимчасові помилки |

OAuth-тести використовують синтетичні реквізити, підставний HttpMessageHandler та локальний HTTP callback на випадковому IPv4 loopback-порту. Вони не звертаються до справжнього Google API. Сховище сеансу в unit-тестах підмінене пам’яттю; це перевіряє поведінку сервісу, але не замінює перевірку Windows SecureStorage після реального перезапуску.

## Сумісність ANTLR

Окрема тимчасова діагностична програма порівняла новий і колишній парсери: 5 000 згенерованих коректних формул дали однакові AST, ще 5 000 випадкових входів збіглися за прийняттям/відхиленням та деревами. Діагностична програма не входить до проєкту.

Таблиця 100 × 100 містила 10 000 заповнених клітинок із формулами й залежностями від попереднього рядка. Усі результати правильні; обчислення ядра в цьому запуску зайняло 125 мс. Це вимір конкретного середовища, без малювання UI та мережевих операцій.

## Збірка та межі перевірки

MAUI Windows x64 Release успішно зібрано: **0 попереджень, 0 помилок**. Підтверджено наявність ANTLR runtime і ліцензії у вихідній папці збірки. Звичайна збірка використовує готові C# файли з `Parsing/Generated` і не потребує Java. [Інструкція ANTLR](ANTLR.md).

Локальний SDK 11.0.100-rc.3 використано як хост збірки; цільові фреймворки залишаються .NET 10. На комп’ютері розробника потрібні відповідний SDK і MAUI Windows workload.

Користувач підтвердив реальні вхід у Google, збереження, повторне відкриття й оновлення таблиці до переходу парсера на ANTLR. Поточну ANTLR-збірку не перевірено інтерактивно у вікні MAUI; також залишається перевірити відновлення авторизації після реального перезапуску на комп’ютері користувача. Автоматизовані перевірки ядра не підтверджують усі можливі UI-сценарії або повну відсутність помилок.
