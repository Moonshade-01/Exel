# Перевірка Exel

Дата: 2026-10-24. Windows x64; застосунок .NET 10 / MAUI 10.0.110, ядро й інтеграція — net10.0.

## Автоматизовані тести

**123 тести пройшли, 0 помилок, 0 пропущених.** Підтверджений запуск через .NET SDK 10.0.402. Тестовий проєкт використовує Microsoft.NET.Test.Sdk 18.7.0, xUnit 2.9.3 та адаптер xunit.runner.visualstudio 4.0.1.

```powershell
dotnet test tests/Exel.Tests/Exel.Tests.csproj -c Release
```

Тести розташовано в `tests/Exel.Tests`. Вони не запускають MAUI та не використовують справжні Google-реквізити.

OAuth-тести виконують справжній локальний HTTP callback на випадковому IPv4 loopback-порту. Запити до Google перехоплює підставний HttpMessageHandler. Callback використовує TcpListener і не потребує реєстрації URL в HTTP.sys або прав адміністратора. Тестові клієнт, код і токени синтетичні.

## Перевірка у вікні

Підтверджено вручну через Computer Use:

- запуск нативного MAUI-вікна й відкриття вбудованого прикладу;
- повні українські системні заголовки «Exel — Нова таблиця» та «Exel — Приклад посилань», зокрема в accessibility-даних Windows;
- один клік по клітинці → Ctrl+A: виділено весь текст 15 без попереднього подвійного кліку;
- редагування A2 до 21 → Enter: вибір перейшов до A3, B2 стало 42, C2 — 62;
- у формулі A3 введено =, кнопкою «Посилання» та кліком вставлено A2; після застосування A3 = 21;
- F2 відкриває редактор, Tab після редагування A3 переводить вибір до B3;
- фактичне збереження через системний Save As: записаний JSON містить A2 = 21 та A3 = =A2; документ стає збереженим і з’являється в нещодавніх;
- діалог незбережених змін: «Зберегти» відкриває Save As, скасування Save As залишає документ, «Не зберігати» дозволяє продовжити, «Скасувати» повертає до таблиці;
- Undo відновлює попередню формулу й значення.

Перелік не означає перевірку кожної можливої послідовності дій, кожного розміру екрана чи всіх допоміжних технологій. Намальовані клітинки не є окремими accessibility-контролами; повне озвучення сітки не реалізоване.

## Навантаження

Окрема діагностична програма заповнила 200 × 52 = 10 400 клітинок виразом `2^100+17mod5`. Усі результати правильні; перерахунок ядра в цьому середовищі зайняв близько **114 мс**. Це вимір обчислення, а не гарантія часу повного UI-сценарію на будь-якому комп’ютері. Перевірено відкриття й обчислення прикладів та негайне скасування завдання.

## Межі перевірки

Реальна згода Google, доступ до особистого Drive й наскрізний обмін зі справжнім Google API ще потребують участі власника акаунта. Підставний транспорт перевіряє контракт запитів і відповідей, але не замінює цей сценарій. Інструкція: [GOOGLE_DRIVE.uk.md](GOOGLE_DRIVE.uk.md).

Готовий Windows-пакет містить .NET 10 і Windows App SDK. У цьому середовищі MAUI-публікація використовує SDK 11 як хост через неповний набір MAUI workload у локальному SDK 10; ціль і runtime залишаються .NET 10. Тести ядра та інтеграції окремо успішно запущено SDK 10.0.402. На іншій машині для вихідного MAUI-проєкту потрібен повний MAUI Windows workload під .NET 10.
