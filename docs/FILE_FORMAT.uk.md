# Чому таблиця зберігається як JSON

Exel має власний формат `.isheet.json`. Він зберігає назву, розміри та початкові формули клітинок. Обчислені значення після відкриття відтворюються з формул, тому файл не містить застарілого кешу. JSON зручно переглядати як текст, перевіряти й передавати на Google Drive без втрати запису виразів.

Це не файл Excel. XLSX — інший формат із книгами, аркушами, стилями, типами клітинок та власними формулами. Просте перейменування `.json` на `.xlsx` не перетворює документ.

| Властивість | Exel JSON | Майбутній XLSX-обмін |
| --- | --- | --- |
| Формули Exel | Зберігаються дослівно | Потрібне узгоджене перетворення синтаксису |
| div / mod | Оператори нашої мови | В Excel використовуються інші функції та правила |
| Великі цілі | Зберігається текст числа/формули, обчислює BigInteger | Для точного перенесення довгі цілі потрібно записувати текстом |
| Відкриття в Microsoft Excel | Власний формат застосунку | XLSX можна відкрити як книгу |
| Google Drive | Зберігає файл без перетворення | Зберігатиме XLSX, якщо окремо реалізувати експорт |

Excel має обмеження точності числових значень у 15 значущих цифр: [офіційні обмеження Excel](https://support.microsoft.com/en-us/excel/excel-specifications-and-limits). Саме розширення XLSX не гарантує збереження точності BigInteger.

Підтримку XLSX можна додати окремим імпортом/експортом із визначеними правилами для великих чисел, формул і непідтримуваних конструкцій. Зараз її немає. Поточний Google Drive зберігає власний JSON як звичайний файл, без конвертації у Google Sheets.
