# Exel — лабораторна робота № 1

Навчальна електронна таблиця на C# / .NET MAUI. **Варіант 6: набори операцій 1, 2, 4, 6.** Інтерфейс українською, обчислення цілих чисел через `System.Numerics.BigInteger`.

Застосунок містить нативний інтерфейс Windows, аналіз і обчислення формул, локальні документи та інтеграцію Google Drive.

## Запуск Exel

Завантажте `Exel-Windows.zip`, повністю розпакуйте його в окрему папку й відкрийте **Exel.exe** подвійним кліком. Не запускайте зсередини ZIP і не переносіть лише EXE без сусідніх файлів. Це Release-збірка для Windows x64 із .NET 10 та Windows App SDK у комплекті; для її запуску не потрібні Visual Studio, SDK, MAUI workload або повторне складання. Папка більша за архів вихідного коду, бо містить залежності.

Можна створити звичайний ярлик на EXE. Запуск з готової папки не звертається до NuGet і не виконує збірку.

Якщо працюєте з вихідним кодом: один раз відкрийте `Build-Release.cmd`, а далі запускайте `Start.cmd`. Після змін у коді повторіть `Build-Release.cmd`. Якщо ви вже збирали проєкт, `Start.cmd` також знаходить наявну Release/Debug збірку. Для складання потрібне середовище .NET 10 / MAUI Windows, описане нижче.

## Інтерфейс і робота з таблицею

**Exel** розміщено в крайньому лівому куті основної верхньої панелі; під ним — назву документа. Власна темна палітра поєднує графітові поверхні, сині заголовки та бурштинові акценти. Команди згруповано нагорі, а більшу частину вікна займає таблиця. Бічну панель документів можна сховати. Це нативний застосунок .NET MAUI, без HTML/WebView.

Доступне скасування й повторення змін (Undo/Redo), окрему перевірку синтаксису, видалення останнього рядка/стовпця, нещодавні документи, вибір робочої папки, вбудовані приклади та системне вікно збереження. Назва, дані й розміри документа входять до історії останніх 40 змін. Історія діє до заміни документа; після перезапуску не відновлюється.

Початкова таблиця порожня, 100 × 26. Поле адреси дозволяє перейти, наприклад, до Z100. Колесо прокручує рядки, Shift+колесо — стовпці; на краях сітки є звичайні смуги прокручування.

Один клік вибирає клітинку. Подвійний клік, F2 або Ctrl+A після вибору відкривають редагування безпосередньо в клітинці. Ctrl+A виділяє всю формулу. Enter застосовує й переходить вниз, Tab у клітинці — праворуч, Escape скасовує незастосований текст редактора. Стрілки переміщують вибір, коли редагування завершене. Верхній рядок формули синхронізований із клітинкою. Кнопки реагують коротким зменшенням і зміною прозорості, вибір клітинки — анімацією рамки.

### Як працюють посилання

У A1 введіть `10`, у B1 — `A1*2` або `=A1*2`: B1 дорівнює 20. Змініть A1 на 15 — після застосування B1 стане 30. Адреси пишуться латиницею. Порожня клітинка в посиланні дорівнює нулю.

Щоб вставити адресу кліком, виберіть клітинку з майбутньою формулою, введіть `=` чи початок виразу, поставте курсор у місце вставлення, натисніть **«↗ Посилання»**, потім потрібну клітинку таблиці. Її адреса вставляється у формулу вихідної клітинки. Продовжуйте вираз і застосуйте. Для наступної адреси знову натисніть «Посилання». Без цієї кнопки клік звичайно змінює вибрану клітинку.

Початковий `=` необов’язковий. Підтримуються компактні формули `5^8`, `17div5`, `A1modB2`, `max(A1,B2)` та формули з пробілами. Пробіли всередині числа не зливаються: `1 2` є помилкою.

### Клавіші

| Клавіші | Дія |
| --- | --- |
| Ctrl+N / Ctrl+O / Ctrl+S | нова / відкрити / зберегти |
| Ctrl+Z / Ctrl+Y | скасувати / повторити зміну документа при фокусі в сітці; у текстовому полі діє його нативна історія |
| F2 / Ctrl+A | редагувати / виділити текст клітинки |
| Enter / Tab | вниз / праворуч після застосування редагування клітинки |
| Стрілки, PageUp/PageDown | навігація поза редактором |
| Home / Ctrl+Home | перший стовпець рядка / A1 |
| Delete | очистити вибрану клітинку поза редактором |

«Синтаксис» перевіряє правильність запису без арифметики. Наприклад, `10div0` синтаксично правильне, але «Обчислити» поверне #DIV0. «Формули / Значення» перемикає показ початкових виразів і результатів. «Повне значення» відкриває довге число для перегляду й копіювання, «Помилки» — пояснення помилкових клітинок.

## Складання з вихідного коду

Проєкт призначено лише для **Windows 10 1809+ / Windows 11** і **.NET 10**. Потрібні .NET SDK 10.0.402 (або сумісне оновлення цього SDK) та MAUI Windows workload для .NET 10. Інші платформи не входять до цільових платформ проєкту. Відкривайте рішення в сумісній Visual Studio з компонентом .NET MAUI.

```powershell
dotnet workload install maui-windows
dotnet restore Exel.sln
dotnet build Exel.sln
dotnet build src/Exel/Exel.csproj -t:Run
```

Перший restore завантажує пакети з NuGet. Потрібен інтернет. `global.json` фіксує SDK для відтворюваної збірки. Для переходу на інший SDK слід узгоджено змінити його версію, MAUI workload і TargetFramework обох проєктів.

## Документи та розміри

У меню «Файл» доступне перейменування документа й «Зберегти як». Зірочка в заголовку означає незбережені зміни, зокрема незастосований текст. Основні дії меню продубльовано кнопками нагорі.

Додавання рядка/стовпця розширює таблицю знизу/праворуч до 200 × 52 (AZ). Видалення забирає **останній** рядок/стовпець разом із даними. Посилання не зсуваються: адреса поза новими розмірами дає #REF. Undo повертає попередні розміри й дані. Видалення довільного вибраного рядка зі зсувом адрес не реалізоване.

У панелі «Документи» є останні відкриті/збережені файли та три вбудовані приклади: великі числа, посилання, цикли й помилки. «Обрати папку» показує до 12 найновіших JSON-файлів у вибраній папці. Запам’ятовуються локальні шляхи останніх 7 документів і папка, а не їхній вміст. Приклади відкриваються навіть без зовнішньої папки samples.

## Мова формул

| Можливість | Приклад | Результат |
| --- | --- | --- |
| Велике ціле | `123456789012345678901234567890` | без переповнення Int64 |
| Пріоритет операцій | `2+3*4` | `14` |
| Дужки | `(2+3)*4` | `20` |
| Ділення | `17/5`, `17div5` | `3` |
| Остача | `17mod5` | `2` |
| Степінь | `2^3^2` | `512` |
| Максимум/мінімум | `max(10,min(7,20))` | `10` |
| Посилання | `A1+max(B2,10)` | залежить від клітинок |
| Від’ємне число | `(0-17)div5` | `-3` |

Адреси пишуться латиницею: `A1`, `B12`, `AZ200`. Регістр адрес і слів `div`, `mod`, `max`, `min` неважливий. `A01` не є коректною адресою. Числа — десяткові цілі без роздільників тисяч і десяткової частини. Пробіли й перенесення рядка ігноруються між токенами; злиті операнди на кшталт `12A1` або `A1B2` відхиляються.

Пріоритет від вищого до нижчого: дужки/функції → `^` → `*`, `/`, `div`, `mod` → `+`, `-`. Степінь правоасоціативний, решта операцій лівоасоціативні. `max`/`min` мають рівно два аргументи через кому. Унарні `+` і `-` не реалізовані: вони належать набору 3, якого немає у варіанті 6. Для від’ємного числа використовуйте `(0 - число)`.

Правила, які умова не деталізує, прийнято явно: `/` та `div` однаково відкидають дробову частину в напрямку нуля; `mod` має знак діленого. Наприклад, `(0 - 17) mod 5 = -2`. Порожня клітинка в посиланні дорівнює нулю. `0 ^ 0 = 1`. Від’ємний показник степеня відхиляється, оскільки результат має залишатися цілим.

Формальний опис: [docs/GRAMMAR.md](docs/GRAMMAR.md). Це БНФ, без UML або діаграм Вірта.

## Архітектура та логіка

`Exel.Core` не залежить від MAUI: містить модель таблиці, адресацію, парсер, AST, обчислення та JSON-серіалізацію. `Exel` містить інтерфейс, а `Exel.Integration` — незалежний сервіс Google Drive з підставним HTTP-транспортом для тестування.

- `FormulaParser` перетворює текст на токени з позиціями й виконує рекурсивний спуск. Числа стають `BigInteger`, а посилання залишаються вузлами AST. Обчислення на цьому етапі немає.
- `WorkbookCalculator` спочатку розбирає всі заповнені клітинки, потім обчислює AST. Це забезпечує відокремлення синтаксичних та обчислювальних помилок.
- Посилання обходяться в глибину; множина активних клітинок виявляє цикли. Кеш результатів діє лише в межах одного перерахунку, тому редагування не залишає старих значень.
- Для степеня застосовано піднесення до степеня двійковим методом. Усі арифметичні значення залишаються `BigInteger`; Int32 використовується для координат та обмеженого показника степеня.
- Перерахунок працює у фоновому завданні на копії таблиці. Повторні команди під час операції ігноруються; інтерфейс не вимикається масово. Кнопка скасування лишається доступною. Незмінені результати повторно використовуються при виборі клітинки та зміні режиму.

Це навчальна реалізація: після застосування зміни перераховується вся таблиця. Інкрементальний граф залежностей не реалізовано. Undo/Redo зберігає до 40 станів таблиці; рядки формул незмінні й спільно використовуються між копіями словника.

## Помилки та обмеження

| Код | Причина |
| --- | --- |
| `#SYNTAX` | неправильний токен, пропущена дужка, зайвий аргумент, відсутня операція |
| `#DIV0` | ділення або mod на нуль |
| `#REF` | коректна за формою адреса поза розмірами таблиці |
| `#CYCLE` | пряме або непряме циклічне посилання |
| `#DOMAIN` | від’ємний показник степеня |
| `#LIMIT` | перевищено обчислювальні обмеження |

BigInteger усуває фіксовану розрядність машинних цілих, але програма має практичні межі: 4096 символів у формулі, 65536 біт у результаті (приблизно 19729 десяткових цифр), показник до 100000, вкладеність парсера та ланцюжок залежностей до 128, сумарна глибина обчислення AST і посилань до 256, бюджет 1000000 вузлів на перерахунок, тайм-аут перерахунку 5 секунд. Це захищає інтерфейс від випадково надмірних обчислень. Файли перевіряються за розміром та структурою; межа 4 МБ.

## Локальні файли

Формат `.isheet.json` зберігає версію схеми, назву, розміри й словник **початкових формул**. Значення не зберігаються, а обчислюються після відкриття. Це власний формат, не Excel XLSX і не Google Sheets.

Відкриття, перше збереження та «Зберегти як» використовують системні діалоги Windows. Звичайне «Зберегти» оновлює поточний локальний файл. Скасування діалогу не змінює поточний шлях. Запис спочатку здійснюється в тимчасовий файл поруч, після чого він замінює цільовий файл. Збережений файл додається до нещодавніх документів.

Перед створенням нової таблиці, відкриттям іншої та закриттям вікна застосунок пропонує «Зберегти», «Не зберігати» або «Скасувати». Якщо збереження не вдалося або системний діалог збереження скасовано, документ залишається відкритим. Автозбереження не реалізовано.

## Google Drive

Реалізовано OAuth 2.0 Desktop flow через системний браузер, PKCE S256, перевірку state та loopback callback `127.0.0.1` на випадковому порту. Доступ — `drive.file`: застосунок працює зі створеними ним файлами. Це не доступ до всього Drive.

Налаштування виконує власник Google-проєкту:

1. Створіть проєкт у Google Cloud Console та увімкніть Google Drive API.
2. Налаштуйте Google Auth Platform / OAuth consent screen. Якщо застосунок у режимі Testing, додайте свій Google-акаунт до test users.
3. Створіть OAuth client типу **Desktop app** та завантажте JSON. Не обирайте Web application.
4. У програмі натисніть «Google Drive» → «Імпортувати OAuth JSON і увійти» та виберіть цей файл.
5. Завершіть згоду в системному браузері й поверніться до програми. Час очікування входу — 3 хвилини.
6. «Зберегти в Drive» створює JSON-файл у Drive; повторне збереження поточного хмарного документа оновлює його за ID.
7. «Відкрити з Drive» показує файли з міткою цього застосунку. Однакові назви розрізняються номерами у списку. Локальний JSON, завантажений вручну через сайт Drive, не має мітки й у цьому списку не відображається.

Токени та реквізити OAuth існують лише в пам’яті процесу, не входять до файлів таблиць і не записуються в репозиторій. Refresh token оновлює access token у межах сеансу. Після перезапуску потрібен повторний імпорт OAuth JSON та вхід. «Вийти» очищає токени програми; це не відкликає згоду в Google-акаунті. Не додавайте справжній OAuth JSON до репозиторію.

У цьому середовищі немає OAuth-клієнта користувача, тому реальний вхід, завантаження та читання з Drive потребують перевірки після налаштування. Програма не підмінює хмарні операції локальними файлами.

Офіційні джерела: [MAUI](https://learn.microsoft.com/dotnet/maui/get-started/first-app), [Google Desktop OAuth](https://developers.google.com/identity/protocols/oauth2/native-app), [Drive upload](https://developers.google.com/workspace/drive/api/guides/manage-uploads).

## Використання генеративного ШІ

Генеративний ШІ використовувався як інструмент допомоги під час підготовки UI, програмної реалізації та документації. Автору роботи необхідно самостійно перевірити результат, зрозуміти реалізацію та адаптувати її до вимог викладача.


## Структура проєкту

```text
Exel.sln
src/
  Exel/                  # Windows MAUI: запуск, UI, нативні діалоги
    UI/                  # головна сторінка, сітка, палітра
    Services/            # локальна бібліотека, діалоги, Unicode-заголовок
    Platforms/Windows/
    Resources/
  Exel.Core/             # без залежності від MAUI
    Documents/           # таблиця, адреси, Undo/Redo
    Parsing/             # токени, AST, синтаксична перевірка
    Calculation/         # BigInteger, залежності, цикли, ліміти
    Persistence/         # формат документа JSON
  Exel.Integration/
    GoogleDrive/         # OAuth, локальний callback, HTTP Drive API
tests/Exel.Tests/         # xUnit: ядро, файли, історія, Drive
samples/                 # приклади таблиць
docs/                    # БНФ, дизайн, перевірка, інструкція Drive
```
